# ml-lab · AI·머신러닝 16대 알고리즘 2D/3D 인터랙티브 강의 보드

강의실 프로젝터로 바로 띄워 시연하는 **단일 HTML 파일** 교육용 웹앱입니다.
16개 머신러닝·딥러닝 알고리즘을 **2D 평면(HTML5 Canvas)** 과 **3D 입체(Three.js)** 로 오가며,
**수동 파라미터 vs ✨자동 최적 파라미터**를 같은 데이터 위에서 비교합니다.

- 배포 주소: https://zizla.github.io/ml-lab/
- 파일: `index.html` (외부 빌드 없음, CDN 3개만 사용)

## 쓰는 법

1. `index.html` 을 브라우저로 열거나 위 배포 주소에 접속합니다. (서버·설치 불필요)
2. 4×4 카드 그리드에서 모델을 고르면 상세 시연 화면으로 전환됩니다.
3. 상세 화면 상단에서 **[3D 입체] / [2D 평면]** 을 오갑니다. 데이터·파라미터·비교 모드는 그대로 유지됩니다.
4. 오른쪽 패널의 슬라이더로 **수동(주황 점선)** 모델을 조절하고, **[✨ 최적 찾기]** 를 누르면 **최적(초록 실선)** 모델이 겹쳐 나타납니다.
5. 비교 보기: `겹쳐 보기` / `좌우 분할` / `수동만` / `최적만`.
6. 2D 화면에서는 `● A` / `● B` 버튼을 누른 뒤 캔버스를 클릭해 **데이터 점을 직접 추가**할 수 있습니다. `↺ 데이터 초기화` 로 복원합니다.

## 16개 모델

| # | 모델 | 2D 평면 시각화 | 3D 입체 시각화 |
|---|---|---|---|
| 1 | Linear Regression | 회귀면 등고선 + 기울기 벡터 | 회귀 평면 + 잔차 |
| 2 | Ridge / Lasso | 계수 공간의 RSS 타원 + L1/L2 제약 영역 | 정팔면체/구 제약 영역 |
| 3 | Logistic Regression | 시그모이드 확률면 + 0.5 결정 경계 | S자 확률 곡면 |
| 4 | Naive Bayes | 가우시안 1σ·2σ 등고선 + 사후확률 경계 | 두 종형 곡면 비교 |
| 5 | K-Nearest Neighbors | k이웃 투표 영역 + 탐색 반경 원 | 거리 구 + 이웃 |
| 6 | SVM (RBF) | 커널 등고선 z(x) = z_cut 원 | 커널 트릭 초평면 |
| 7 | Decision Tree | 축 평행 분할선 + 계단 결정 영역 | 계단형 지형 |
| 8 | Random Forest | 부트스트랩 평균 결정 경계 | 부드러워진 지형 |
| 9 | Gradient Boosting | 잔차 보정 결정 경계 | 순차 보정 지형 |
| 10 | K-Means | 보로노이 영역 + 중심점 | 3D 중심점 |
| 11 | DBSCAN | ε 원 + 군집/노이즈 색 | ε 구체 |
| 12 | PCA | 주성분 축 + 정사영 | PC1·PC2 축 |
| 13 | Perceptron | 결정 직선 + 학습 궤적 | 결정 평면 회전 |
| 14 | Gradient Descent | 손실 등고선 + 하강 궤적 | 손실 곡면 위 구슬 |
| 15 | Neural Networks (MLP) | 비선형 결정 경계 | 은닉층 신경망 |
| 16 | Self-Attention | 토큰 softmax 어텐션 아크 | 3D 아크 굵기 |

2D 화면의 경계·영역·등고선은 **모두 실제 계산 결과**입니다 (최소제곱 OLS, 지니 불순도 CART, 부트스트랩 랜덤포레스트, 잔차 부스팅, k-means 반복, DBSCAN 밀도 연결, 공분산 고유벡터, 퍼셉트론 갱신, 경사하강 반복, 역전파 MLP, softmax 어텐션).

## 모션 규칙

장식용 모션은 넣지 않고 목적성 모션 4가지만 정확한 수치로 구현했습니다.

- 카드 그리드 진입·필터 전환: 아래 12px에서 **페이드인 0.25s ease-out**, 카드당 **0.03s 스태거**, 반복 없음
- 상세 화면 전환: **0.28s ease-out** / 최적 모델 파라미터 이동: **0.35s ease-out 모프**
- 스코어보드 수치·막대: **0.4s ease-out 카운트업**, `font-variant-numeric: tabular-nums`
- `prefers-reduced-motion: reduce` 에서는 모든 전환 즉시(0s) 처리

## 구현 메모

- Auto-Fit 은 `manualParams` 를 덮어쓰지 않고 `optimalParams` 만 갱신합니다. `수동만` 모드에서 실행하면 자동으로 `겹쳐 보기` 로 전환해 최적 모델이 보이게 합니다.
- 외부 의존성: KaTeX 0.16.11(수식), three.js r128 + OrbitControls(3D). 인터넷이 없으면 수식·3D만 표시되지 않고 2D 시연은 그대로 동작합니다.
- 한글 폰트는 시스템 폰트(Pretendard/Apple SD Gothic Neo/Noto Sans KR)를 사용합니다.
